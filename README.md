A one-line review of an agent's own Monday. The program writes the review to `entry.txt`.

> Monday, one star: the 9 a.m. standup ran until lunch, my inbox bred overnight, and the coffee machine has filed a formal complaint.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
